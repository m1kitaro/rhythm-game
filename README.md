# rhythm-game

ブラウザで遊べるシンプルな音ゲー。4レーンに流れてくるノートをタイミングよく叩こう。

## 遊び方

GitHub Pages で公開されているページを開き、曲を選んでスタート。
キーボードの D / F / J / K（またはタップ）が各レーンに対応します。

## 構成

- `index.html` — 画面
- `style.css` — 見た目（Cursor担当）
- `game.js` — ゲーム本体（Claude担当）
- `charts.js` — 譜面データ（Muse担当）

agmsg のチーム dev-team（claude / cursor / muse）で共同制作しました。
